# E-Commerce Analytics Portfolio

Interactive Streamlit dashboard analyzing 100K+ Brazilian e-commerce orders from the Olist dataset.

**Live App:** [View on Streamlit Cloud](https://ecommerce-analysis-npwkzujfkjou93gfjfvw5k.streamlit.app/)

## Features
- **Exploratory Data Analysis** — temporal, product, geographic patterns with interactive filters
- **Order Fulfillment Funnel** — custom trapezoid funnel + waterfall drop-off chart
- **Delivery Performance** — state-level explorer with statistical significance testing
- **Customer Reviews & Retention** — cohort analysis, segmentation
- **A/B Testing** — hypothesis testing with power analysis + what-if revenue slider
- **Revenue Impact Modeling** — gauge charts with scenario exploration

## Tech Stack
Python · Pandas · NumPy · SciPy · Statsmodels · Plotly · Streamlit

## Run Locally
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Data
Download the [Olist dataset from Kaggle](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce) and place all CSVs in the `Data/` folder.
